Why has our application suddenly slowed down?

A US-based enterprise IT team monitors a business-critical application used across multiple offices. Users report slower response times, but the problem is not affecting everyone. Use the Orbit toolbar on each chart to locate the slowdown and what may be driving it.

The Orbit toolbar did not load. Serve this page from a domain on the Orbit installation's referrer allowlist; opened from a local file the charts degrade silently to plain Highcharts.

The investigation

  1. Insights: on the response-time chart, Orbit highlights the sharp increase while overall application usage stays normal.
  2. Filter / focus: most regions remain normal; the Northeast shows higher latency.
  3. Compare clusters: one server cluster serving the Northeast is much slower than the others.
  4. Correlations: response time, error rate and memory usage on that cluster all rise together.
  5. Annotate: mark the 2.14.0 deployment on the charts; the deterioration begins shortly after.
  6. Control limits: response time and memory usage have moved outside their expected ranges.
