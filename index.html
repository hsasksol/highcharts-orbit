Six questions, one toolbar

Each demo starts from a question a real dashboard user would ask, and answers it with the Orbit toolbar: summary statistics, anomaly detection, control limits, forecasts, correlations, contribution, filtering and annotations on ordinary Highcharts charts.

01 · Internal dashboards

Why are orders suddenly taking longer to fulfill?

An operations dashboard where fulfillment time climbs while order volume stays flat. Trace the slowdown to one warehouse, one category and one carrier.

Insights · Filter · Correlations · Contribution
02 · Embedded / SaaS

Why did my online sales suddenly drop?

A merchant dashboard where sales fall 18% despite normal traffic. Isolate the drop to mobile visitors from Paid Search and a cart abandonment spike.

Insights · Forecast · Anomaly · Correlations
03 · Financial services

Why has our portfolio suddenly become more volatile?

A risk dashboard where volatility triples while value holds up. Find the sector driving the variance and the holdings that started moving in lockstep.

Anomaly · Contribution · Correlations · Indicators
04 · Scientific / industrial

Is this machine starting to fail?

Sensor telemetry where one machine drifts past its control limits with vibration spikes, rising temperature and rising power draw.

Control limits · Anomaly · Forecast · Annotate
05 · Publishers / media

Why did this story attract a huge audience but so few subscribers?

An editorial dashboard where a viral story is the outlier: 1M pageviews from social, almost no subscriptions. Engagement, not reach, predicts conversion.

Insights · Contribution · Correlations · Annotate
06 · Enterprise software

Why has our application suddenly slowed down?

An IT operations dashboard where response time doubles after a deployment. Narrow it to one region, then one server cluster, with errors and memory rising in step.

Insights · Filter · Correlations · Control limits
All demos use deterministic dummy data and generic names; no real organization's figures. Charts require the page to be served from a domain on the Orbit installation's referrer allowlist for the toolbar to appear.
