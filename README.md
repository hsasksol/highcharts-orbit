# Highcharts Orbit use case demos

Six self-contained demos, one Orbit capability per page.

Live: https://highcharts-orbit.vercel.app/

Local viewing: run start-demos.bat (serves on http://localhost:8123; opening
the html files directly from disk does not work because code.highcharts.com
requires an http(s) Referer).

Dummy data only, deterministic, time axes anchored so the last point is today.
